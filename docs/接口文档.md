# 校园头条接口文档

- 基础地址：`http://127.0.0.1:8080/api`
- 认证方式：请求头 `Authorization: Bearer <token>`
- 角色：ap_user.role = 0 普通用户、1 作者、2 审核员；作者/审核员额外关联 wm_user
- 统一响应：

```json
{ "code": 0, "message": "ok", "data": {} }
```

`code = 0` 成功；`401` 未登录/过期/角色不符；`403` 无审核权限；其余为业务错误。

分页数据结构：`{ "records": [], "total": 0, "page": 1, "size": 10 }`。

## 一、认证与个人中心

### 1.1 自媒体登录

`POST /media/auth/login`

```json
{ "username": "13900000002", "password": "123456" }
```

`username` 可填手机号（推荐）或旧版用户名（admin/cs/photo/job）；仅作者、审核员可登录。

响应 `data`：

```json
{
  "token": "eyJhbGciOi...",
  "id": 14,
  "name": "计算机学院",
  "avatar": "/avatars/m2.svg",
  "role": "MEDIA",
  "userRole": 1,
  "wmUserId": 2,
  "account": "13900000002",
  "accountRole": 0
}
```

- `userRole`：0 普通用户、1 作者、2 审核员；
- `accountRole`：0 作者、1 审核员；
- 普通用户（role=0）不能登录创作端；作者不能进入审核工作台。

### 1.2 发送验证码

`POST /auth/send-code?phone=13800138000`

开发环境验证码固定为 `123456`。

### 1.3 验证码登录

`POST /auth/login`

```json
{ "phone": "13800138000", "code": "123456" }
```

### 1.4 密码登录

`POST /auth/login/password`

```json
{ "phone": "13800138000", "password": "123456" }
```

### 1.5 注册

`POST /auth/register`

```json
{
  "phone": "13900002222",
  "nickname": "摄影小助手",
  "password": "abc123",
  "confirmPassword": "abc123",
  "role": 1
}
```

- role：0 普通用户、1 作者、2 审核员；
- 作者/审核员注册时自动创建关联的 wm_user；
- 手机号唯一；密码 6-20 位，使用 BCrypt 存储；注册成功直接返回 token。

### 1.6 当前用户

`GET /auth/me`（需登录 token，普通用户与作者/审核员均可）

```json
{
  "id": 13,
  "name": "摄影小助手",
  "avatar": "/avatars/u5.svg",
  "role": "USER",
  "account": "13900002222",
  "bio": "摄影社 2024 级",
  "gender": 2
}
```

### 1.7 修改个人资料

`PUT /auth/profile`（需 USER token）

```json
{
  "nickname": "摄影小助手",
  "bio": "摄影社 2024 级，喜欢用镜头记录校园的四季。",
  "gender": 2,
  "avatar": "/avatars/u5.svg"
}
```

### 1.8 上传头像

`POST /auth/avatar`（需登录，`multipart/form-data`，字段 `file`）

头像二进制写入 `ap_user.avatar_data`，返回更新后的用户信息，其中 `avatar` 为
`/api/auth/avatar/{id}?v=时间戳`。

### 1.9 读取头像

`GET /auth/avatar/{id}`（公开）

从 `ap_user.avatar_data` 读取二进制并返回对应 MIME 类型。

### 1.10 退出登录

`POST /auth/logout`（需登录 token），前端同时清除本地 token。

### 1.11 创作端个人资料

作者/审核员复用统一账号，以下接口需要创作端 token：

- `GET /media/auth/me` 当前作者/审核员信息（含 userRole、accountRole、bio、gender）
- `PUT /media/auth/profile` 修改昵称、简介、性别、头像（同步 wm_user 的名称与头像）
- `POST /media/auth/avatar` 上传头像，`multipart/form-data`，字段 `file`，二进制写入 `ap_user.avatar_data`

```json
{
  "nickname": "校园摄影师",
  "bio": "摄影社 2024 级",
  "gender": 2,
  "avatar": "/api/auth/avatar/17?v=20261027104000"
}
```

## 二、频道

`GET /channels` —— 频道列表。

`GET /channels/stats` —— 各频道已发布文章数（MyBatis foreach 统计）：

```json
[
  { "id": 1, "name": "校园", "total": 6 },
  { "id": 2, "name": "学院", "total": 3 }
]
```

## 三、自媒体端

### 3.1 素材

- `GET /media/materials?page=1&size=20&collected=true`
- `POST /media/materials`（multipart，字段 `file`，jpg/png/webp/gif，≤10MB）
- `PUT /media/materials/{id}/collect`
- `DELETE /media/materials/{id}`

### 3.2 文章

- `POST /media/news` 新建（`submit=false` 草稿，`true` 提交审核）
- `PUT /media/news/{id}` 更新
- `POST /media/news/{id}/submit` 提交审核
- `GET /media/news` 内容列表：`status / keyword / channelId / startDate / endDate / page / size`
- `GET /media/news/{id}` 详情（编辑回填）
- `DELETE /media/news/{id}`

保存请求体：

```json
{
  "title": "校园秋日摄影展开幕",
  "content": "<p>正文 HTML</p>",
  "channelId": 1,
  "labels": ["摄影", "展览"],
  "coverType": 3,
  "coverImages": ["/covers/c13.svg", "/covers/c01.svg", "/covers/c02.svg"],
  "submit": true
}
```

内容列表使用 `NewsMapper.xml` 动态 SQL（where/if/choose）实现多条件检索。

## 四、审核工作台（仅审核员）

### 4.1 待审列表

`GET /media/audit/news?status=1&page=1&size=10`

`status`：1 待审核、2 已通过、3 已驳回；不传默认 1。

### 4.2 稿件详情

`GET /media/audit/news/{id}`

### 4.3 审核

`POST /media/audit/news/{id}/review`

```json
{ "pass": true, "reason": "内容符合校园头条发布规范" }
```

- `pass=true`：状态改为 2，写入 `publish_time`；
- `pass=false`：必须填写 `reason`，状态改为 3；
- 同时写入 `audit_record`（审核人、结果、意见、时间），由 `@Transactional` 保证一致性。

## 五、图片文件

### 5.1 读取素材/封面

`GET /files/material/{id}`（公开）

从 `material.data` 读取图片二进制，返回 `image/png` 等 MIME 类型；新闻封面
`cover_images` 中保存的就是该接口地址，因此重新登录后仍可读取。

## 六、用户端

### 5.1 文章列表

`GET /news?channelId=1&keyword=考研&page=1&size=10`

仅返回已发布文章，置顶优先、发布时间倒序。

### 5.2 文章详情

`GET /news/{id}`，阅读数 +1；登录用户返回 `liked`。

### 5.3 点赞 / 取消点赞

`POST /news/{id}/like`（需 USER token）

```json
{ "liked": true, "likes": 187 }
```

### 5.4 评论

- `GET /news/{id}/comments`
- `POST /news/{id}/comments`（需 USER token）

```json
{ "content": "期待开学典礼！" }
```

## 七、健康检查

`GET /health`

```json
{ "code": 0, "data": { "status": "UP", "database": "UP" } }
```

## 八、错误码

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数错误 / 业务校验失败 |
| 401 | 未登录、token 过期或角色不匹配 |
| 403 | 无审核权限 |
| 404 | 文章不存在或已下架 |
| 500 | 服务器异常 |
